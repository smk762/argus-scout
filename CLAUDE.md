# CLAUDE.md — argus-scout

Guidance for AI agents working in this repo. Human-facing usage lives in [README.md](README.md); this file is the orientation an agent needs to change code safely.

> Scaffolded from [`argus-pkg-template`](https://github.com/smk762/argus-pkg-template). Flesh out **Must never happen**, **Layout** and **Gotchas** below as the code grows — the suite conventions are already correct and shared.

## What this is

Homelab intelligence for the Argus suite: reads your telemetry, reasons about it, and reports back with briefings and recommendations it never acts on.

**Advisory only.** Scout reads (Prometheus via PromQL, status events sent to it) and reports (briefings, recommendations). It never executes, deploys or dispatches anything, and never scrapes or connects to the hosts it reports on. A standing approval may move a recommendation to `approved`; nothing moves it further except a person.

Development runs in phases tracked by the epic issue in this repo. The policy core was ported from a private deployment (mithrandir) with its globals removed: every module takes its config explicitly.

Shared code — the target taxonomy, wire-schema versioning, and the local/remote model contract — lives in **argus-cortex**; import it rather than re-implementing.

## Layout

`src/argus_scout/` — the package. Key modules:

- `__init__.py` — version shim (`__version__` from `hatch-vcs`).
- `cli.py` — Typer app; entry point `argus-scout` (`[project.scripts]`). `init` writes a starter config; `check` validates config files (`check config` covers scout.yaml, every file it names and every source and channel entry); `deliver --config --latest [--kind] [--channel] [--force]` (re-sends the newest report; idempotent unless `--force`); `poll --config [--source] [--ingest]` (one poll, dry run by default); `analyze --config [--dry-run]` (one signal evaluation + engine cycle; `--dry-run` works on `SqliteStore.copy_of`); `brief --config --kind morning|evening|status [--dry-run] [--no-llm]` (writes one report and prints it; `--dry-run` stores nothing and doesn't persist the usage count); `tariff now`; `serve --config`.
- `config.py` — `ScoutConfig`, the one config file (`scout.yaml`): `files`, `store`, `sources` (built-in kinds `webhook` / `json_poll` validated here; any other kind loads as `PluginSource`, keys kept, and is validated by its plugin's `config_model` in `sources.build_sources`; plugin models subclass `SourceSettings`), `channels` (built-in `text` / `webhook`, plugin kinds as `PluginChannel` validated by `channels.build_channels`; every channel has `enabled`, `min_severity`, `kinds`, `timeout` from `ChannelSettings`), `schedule` (briefing kinds are `morning` / `evening` / `status`), `services` (`llm`: `backend` ollama|openai, `base_url`, `model`, `api_key_env`, `timeout`, `max_tokens`, `context_tokens`, `temperature`, `gpu` (`LLMGpuConfig`: `min_vram_mb`, `model_mb`, `priority`, `target`; present means a lease per call; `target` required for openai)), `budget` (`limits: {llm_calls: N}`, `block_manual`), `server`. `files` also names `persona` and `memory`. Pydantic v2, `extra="forbid"`, frozen. `load_config` resolves relative paths against the config's directory, loads `.env` beside it (never overriding the real env) and raises `ConfigError` on anything invalid. Secrets are env-var *names* (`token_env`, `auth_env`, `api_key_env`), read with `resolve_secret` as `SecretStr`.
- `severity.py` — `Severity` (info < notice < warning < critical), `coerce_severity`, `rank`.
- `events.py` — `StatusEvent`, the envelope every source sends; `fingerprint` (content identity, never `speech`), `spoken` (`speech` or summary) and `group_duplicates`.
- `heartbeat.py` — `HeartbeatPolicy` (defaults + YAML overrides, `origin` per key), `PolicyFile` (mtime reload), the `broadcast_gate` / `report_gate` / `voice_gate` chain and `explain()`, `reannounce_due` (per group, from `last_broadcast_at`). `voice.on_change_only` is applied by the status cycle; `voice.backoff_max_seconds` was never implemented and is ignored with a warning.
- `recommendations.py` — `Recommendation` (`to_dict` / `from_dict`; `key`, `expires_at`, `last_seen_at`, `retired_reason` default empty so older stored rows load), `Status`, `TRANSITIONS` (`proposed → retired` withdraws a stale proposal); `approve()` / `reject()` / `retire()` take an optional `now` and keep the audit trail.
- `prometheus.py` — `PrometheusClient(base_url, fetcher=)`: read-only `query` / `query_range` via `argus_cortex.net.afetch`, configured host the only one allowlisted, no redirects. Typed results (`Sample`, `Series`) and errors (`PrometheusUnavailable`, `PrometheusQueryError`, `PrometheusResponseError`, all `PrometheusError`): a failure is unknown, never an empty result.
- `signals.py` — declarative rules (`SignalRule`: `name`, `query`, `op`, `threshold`, `for`, `severity`, `escalate`, `labels_key`, `labels`, `rejection_ttl`, `expires_after`, `recommendation`). `parse_rules` / `load_signal_rules` skip bad rules with an error; `SignalRulesFile` (mtime reload). `render` / `template_fields`: allowlisted plain-name placeholders, precision-only specs on numbers, no `format_map`. `SignalState` (pending `for` clocks, persisted via the store). `async evaluate(rules, client, now, state=)` → `Evaluation` (a `list[SignalHit]` plus `evaluated` / `unknown` / `pending`); `dedup_key`; `make_hit` and `Evaluation.merge` are the seam for other evaluators (tariff rules). `kind:` picks a rule's schema (`rule_kinds()`; missing means `threshold`); `evaluate` runs only threshold rules but keeps every rule's pending state; `RuleBase` is the shared base (name, query, severity, rejection_ttl, expires_after, recommendation, template check).
- `tariff_rules.py` — the tariff-aware kinds. `TariffShiftRule` (`kind: tariff_shift`: `unit` W/kW/kWh, `min_shiftable`, `duration`, `periods`, `horizon` ≤ 1d, `min_saving`, `for`, `labels_key`) and `TariffPlanRule` (`kind: tariff_plan`: `unit`, `window`, `step`, `every` ≥ 1d, `min_saving`, `min_coverage`). `async evaluate_tariff(rules, client, tariff, now, tz=, state=, tariff_error=)` → `Evaluation`; no tariff / gaps / non-kWh / unknown period → `unknown` with `skipped: ...`; a plan rule's last run is kept in `SignalState` under `last_run`. Maths: `energy_kwh`, `shift_saving`, `cheaper_ahead`, `usage_points`, `plan_cost`, `comparable_plans`, `format_money` (minor → major units).
- `engine.py` — `RecommendationEngine(store, approvals, clock=, clear_grace=1h, default_ttl=7d)`. `run_cycle(hits)` → `CycleReport` (new / refreshed / auto_approved / retired / suppressed / unknown): dedup by key onto an open recommendation, rejection memory (suppressed unless severity escalates past the rejected one, or the rule's `rejection_ttl` has passed), standing approvals on `proposed` (guardrails win), a standing-approved recommendation escalating past a guardrail retired and re-proposed (`_escalated_past_standing`; a manual approval keeps its approval and gets an evidence note), proposed-only expiry (cleared past grace for an evaluated rule, or past `expires_at`; unknown never clears). `recent_rejections(limit)` → `Rejection`.
- `approvals.py` — `StandingApprovals` (file rules + runtime rules, optionally persisted via a `RuntimeRuleStore`), `guardrail_block`, `briefing_lines`.
- `budget.py` — `DailyBudget` (per-kind daily caps; counts in a `counter=` (`UsageCounter`: the store, atomic across processes), a single-process `state_path` JSON file, or memory; `on_change` hook for gauges), `budget_from_config(config, counter=, persist=, clock=)` (limits from `budget:`; the day rolls over at midnight in `schedule.timezone`; with `counter` the counts live in the store's `usage_counts` table and an old `usage.json` beside the store is imported once (merged by max, renamed `usage.json.migrated`)), `ManualOriginMiddleware`. The server and the CLI pass their store.
- `llm.py` — text generation on `argus_cortex.backends.RemoteBackend` (cortex owns the HTTP client, bearer header, timeout and retry policy: POSTs retried only when they never reached the server). `TextBackend.complete(prompt, max_tokens=)`; `OllamaBackend` (`/api/chat`, `stream: false`, `options.num_predict`), `OpenAICompatBackend` (`{base_url}/chat/completions`, `base_url` includes `/v1`; hosted providers via `api_key_env`); `build_backend(LLMConfig)`. `TextGenerator(backend, budget, call_guard=)`: `await generate(prompt, *, max_tokens, kind="llm_calls")` checks the cap (`LLMBudgetExceeded`, no lease waited for), enters `call_guard()` (the GPU lease: an async context manager, default no-op, held only for the HTTP round-trip), charges the budget, then makes the blocking call in a thread, sent to the grant's `base_url` if it has one (`TextBackend.at(url)`); no lease granted is `LLMGpuUnavailable` (`reason` `gpu_unavailable`, not charged), any other failure `LLMUnavailable` (`reason` tag). `clean_output`: output is untrusted text, never parsed. `estimate_tokens` = chars/4.
- `persona.py` — `Persona` (name, voice, style, do, dont, sign_off, `SpeakableStyle`); the field defaults are the neutral default persona (`examples/persona.yaml` mirrors them, tested). `system_prompt()` always starts with scout's `RULES` (advisory only, facts only, don't re-argue rejections). `PersonaFile(path)` (mtime reload; a bad or missing file → default, `error` set, logged).
- `memory.py` — `Memory(root, max_chars=)`: operator notes (`*.md`, one level, read-only, capped per file) and scout's own `SCOUT_FILE` (`scout-recent-rejections.md`, rewritten atomically, never through a symlink). `resolve(name)` fences every path under the root's real path (`MemoryPathError`). `render_rejection` quotes a rejection's reason.
- `gpu.py` — GPU leases (argus-iris broker via `argus_cortex.gpu`). `narrative_guard(llm, coordinator=)` → the call guard (or `None` without `services.llm.gpu`): one preemptible lease, kind `narrative`, priority `background` by default, target `ollama:<model>` or `gpu.target`. Coordinator from the host-wide `ARGUS_GPU_*` env (`coordinator_from_env`), deliberately no scout.yaml knob. `routed_url` (grant's host, configured path kept), `LEASE_ERRORS`, `TENANT`/`KIND`/`DEFAULTS` (match `gpu-tenant.yaml` at the repo root). Never leases around echo: speech is echo's GPU work.
- `narrative.py` — `Narrator(store, generator=, persona=, memory=, tariff=, tz=, clock=, max_tokens=, context_tokens=)`: `gather(kind, groups=)` → `Facts` (open groups, proposed + approved recommendations, `recent_rejections`, `TariffFact`, notes); `build_prompt` → (`Prompt`, `Selection`): fact lines get a priority tier (critical 1, warning 2, rejections 3, notice 4, info 5, notes 6; header and tariff 0), and `select_lines` takes them in tier order until the next doesn't fit in `(context_tokens - max_tokens) * 4 * 0.9` chars minus the system prompt (monotonic cut; "N more not shown" per section; notes also capped at `memory.max_chars`). `compose()` asks the model, else `render_template` (deterministic, same facts); `report(kind, groups=, use_llm=, dry_run=, meta=)` stores a `Report` with meta (`severity`, `quiet_exempt` and `title` from `delivery_meta`: the worst item, plus for a briefing proposed/approved recommendations, `info` when nothing is open; `path` llm|template, `fallback_reason` budget|gpu_unavailable|error|disabled|no_llm, model, token counts, persona, `fingerprints`, `facts`: ids used and omitted counts). `build_narrator(config, store, budget, tariff=, coordinator=)` (wires `gpu.narrative_guard`).
- `tariff.py` — `Tariff` / `Plan` / `TariffPeriod` / `TariffTier`; `current_period`, `next_period_change`, `coverage_gaps`, `tiered_cost` (units above a capped last tier pay its rate); `TariffFile` (mtime reload, `None` on a bad file). Rates are in the currency's minor unit.
- `scheduler.py` — asyncio `Scheduler(store, clock=, sleep=)`: `add(name, async_fn, trigger, retry_delay=)`, `tick(wait=)`, `run_now`, `run_forever`, `start()` / `stop()`. Triggers: `Every(seconds)` and `DailyAt(time, tz, grace=)` (per-local-date slots, so DST fires once; a missed slot runs late only within `grace`, never a backlog). Last successful run per job persists in the store's `job_runs`, so restarts neither repeat nor reset. A raising job is logged, counted and retried after `retry_delay`; a job never overlaps itself. Clock and sleep are injected: tests never sleep.
- `cycles.py` — the jobs: `StatusCycle(store, policy_file, inbox=)` (reloads the heartbeat policy every run, so a bad edit degrades to defaults; skips rest hours; decides each `Inbox.open_grouped()` group with `explain`; with a `narrator`, writes a `status` report of the groups `report_gate` passed, capped at `report.max_items`, when at least one is news (`is_news`: no event in the group has been announced in its current form, which the store resets on first sight, a fingerprint change and a recurrence, or `reannounce_due`); it then marks the included groups announced (`mark_announced`) and sets `meta.speakable` from the groups whose `Decision.voice` is true (only the news ones under `voice.on_change_only`), or `False`), `AnalysisCycle(store, rules=, client=, approvals=, tariff=, tz=)` (reloads the signals file, evaluates threshold and tariff rules and merges them, runs the engine; skips without Prometheus or rules, and on an unparseable file; an outage makes rules unknown and never raises), `Briefings(narrator, deliver=)` (the one report writer: `write(kind, use_llm=, trigger=, deliver=, wait=)` stores and delivers through the narrator; one report of a kind at a time, `wait=False` raises `ReportBusy`; always held to the caps via `set_manual(False)`), `BriefingJob(kind, store, narrator=, deliver=, briefings=)` (writes through the shared `Briefings`; waits behind an on-request report of its kind), `PollJob(bound_source, inbox)` (one per polling source, ingests via `Inbox.ingest`; with the config's `resolve_missing` and a complete `PollResult`, resolves the source's events the poll no longer lists). `deliver(report)` is the no-op delivery seam (phase 5 injects the channels dispatcher via the jobs' and `register_jobs`' `deliver=`). `register_jobs(scheduler, config, store, policy_file, tariff=, budget=, narrator=, deliver=, dispatcher=, briefings=, approvals=)` (returns the `Briefings`, kept as `Runtime.briefings`) (the runtime passes its `TariffFile`, shared by the analysis cycle and the narrator, its `DailyBudget`, and its `Dispatcher`, which adds the `redeliver` sweep) names them `status`, `analysis`, `redeliver`, `briefing:<kind>@HH:MM`, `poll:<source>`; the name keys the persisted bookkeeping.
- `store/` — persistence (stdlib `sqlite3`, no ORM). `base.py`: the `Store` Protocol plus `InboxEntry`, `Transition`, `Report`, `JobRun`. `sqlite.py`: `SqliteStore(path)` (`":memory:"` for tests) — status events keyed by `(source, event_id)` with first/last seen, ack, fingerprint index and announce state; recommendations with a `recommendation_transitions` audit table (`save_recommendation(rec, by=, reason=, expected_status=, expected_revision=)`: pass the status and revision you loaded, `None` status for a new row; a mismatch raises `StaleRecommendation`, a non-lifecycle status change `IllegalTransition`, both `StoreConflict`, nothing written; every load-then-save in the engine and the routes passes it, the engine logs and skips a conflict, a route answers 409); runtime standing-approval rules (`StandingApprovals(store=...)` loads and writes through; file rules never stored); reports; scheduler `job_runs` (migration 2); recommendation `key` column + index (migration 3; `recommendations_by_key`, `recent_rejections`); signal rules' pending state `signal_pending` (migration 4); delivery records `deliveries` (migration 5: `record_delivery`, `delivered_channels`, `list_deliveries`, `delivery_counts`); events' `resolved_at` (migration 6: `resolve_missing(source, keep)`, a system-side close that open queries and `open_event_counts` exclude and the next sighting clears; never touches `acked_by`); daily usage counts `usage_counts` (migration 7: `usage_counts(day)`, `consume_usage(day, kind, limit, allow_over=)` atomic check-and-increment, `merge_usage` by max; `DailyBudget`'s `UsageCounter`); recommendation revisions `recommendation_revisions` (migration 9, a side table so a replay is harmless: every save bumps it and sets `rec.revision`; a row without one reads as 0; `update_recommendation(rec_id, change, expected_revision=)` checks it and applies `change` to the stored row in one transaction, for the decision routes); `transaction()` groups store calls into one commit (nested calls join it); permanent delivery refusals `delivery_refusals` (migration 8, a side table so a replay is harmless: `record_delivery(..., permanent=)`, `DeliveryRecord.permanent`, `undelivered_reports(since, max_failures=)` → `PendingDelivery` for the redelivery sweep); `copy_of(path)` for dry runs; scrape-time counts for `/metrics` (`recommendation_counts`, `approval_counts`, `open_event_counts`); `prune()`. Migrations are ordered scripts in `MIGRATIONS`, tracked by `PRAGMA user_version` and applied on open: append, never edit a shipped one. One connection behind an `RLock` (shared by the app and scheduler threads), WAL, foreign keys on. Datetimes are UTC ISO text with fixed microseconds, so they compare as strings.
- `inbox.py` — `Inbox(store, clock=)`: `ingest()` / `ingest_many()` (one store transaction for a batch) → `IngestResult` (`Outcome`: new / duplicate / escalated / updated / refreshed / recurred), `ack()`, `resolve_missing(source, present)`, `open()`, `open_grouped()` (→ `EventGroup` by fingerprint, which includes the source). `parse_envelope` is the strict validator for envelopes arriving as data (`InvalidEvent` names the field); `normalise` clips, coerces and strips bookkeeping. Records only: never moves a recommendation or sends anything.
- `sources/` — status sources as plugins. `base.py`: `Source` / `PollingSource` (`async poll`) / `PushSource` (`parse`, `authorize`) protocols, `SourceError`, `SourceAuthError(status)`, `PollResult` (a list with `complete`). `registry.py`: kinds from the `argus_scout.sources` entry-point group (built-ins always present and can't be overridden); `build_sources(config)` → `Sources` (bound sources + per-entry errors). `webhook.py`: `parse_webhook`, `check_token` (argus-cortex `auth.check_bearer`, fails closed), no route. `json_poll.py`: `poll_once` via `argus_cortex.net.afetch`, `map_response` (dotted `items` / `fields`; ids from `id:` paths, else the item's `event_id`, else a hash of summary + payload + link, never severity or timestamps; colliding derived ids fall back to the raw item's hash with a warning; an item naming another source is skipped).
- `channels/` — delivery channels as plugins. `base.py`: `Delivery` (`from_report` / `from_event`; `key` is the idempotency key, `report:<id>` or `event:<source>/<id>:<hash>:<announce count>`; `speakable` is `meta.speakable` or the text through `plain_speech`), `DeliveryResult`, `SpeechAudio`, the `Channel` (`kind`, `config_model`, `async deliver`) / `VoiceChannel` (+ `async play(audio, message)`) / `Synthesiser` protocols, `NullSynthesiser`, `ChannelError(msg, permanent=)` and its `SynthesisError` (`DeliveryResult.permanent` too: a failure the sweep never retries). `registry.py`: kinds from the `argus_scout.channels` entry-point group (a class built with its validated config; built-ins can't be overridden); `build_channels(config)` → `Channels` (bound channels + per-entry errors). `dispatcher.py`: `Dispatcher(channels, synthesiser=, gates=, store=, budget=)`; `deliver(message, force=, only=)` → `DispatchReport` (filters, idempotency via the store, concurrent fan-out with per-channel timeouts, speech synthesised once for all voice channels when the message has a `speakable` and `gates.voice` allows); `HeartbeatGates(policy_file, tz=)` (rest hours, `broadcast_gate`, `voice_gate` for items, `sources.scout` routing for reports); `OpenGates` for tests. `text.py` (append, fenced with `argus_cortex.fs.safe_join` + `O_NOFOLLOW`, rotation), `webhook.py` (`build_payload` schema `argus-scout.delivery` v1, `sign` HMAC, bounded retry via `afetch`; documented in `docs/channels.md`). Voice kinds (built-ins whose numpy is imported only when a channel is built; the constructor raises `MissingExtra` naming the extra): `audio.py` (`decode` wav / `pcm_s16le` / `pcm_f32le` to `Pcm`, `remix`, `resample` linear, `encode` to a `SampleFormat` `rate:bits:channels`, 24-bit in 4 bytes as Snapcast does; `AudioFormatError` for anything else); `snapcast.py` (`SnapcastConfig`; FIFO fenced by `open_fifo`: must exist and be a FIFO, `O_NONBLOCK`, `ENXIO` retried to `open_timeout`; `write_fifo` select + deadline; `SnapcastRpc` JSON-RPC over raw TCP or HTTP to the `control` host only; `plan` = setup calls with their undo, restored in reverse in a `finally`); `mask.py` (`MaskConfig`; `readiness` from `GET /health`; `POST /push?require_screen=true` raw s16le with `X-Sample-Rate` / `X-Audio-Format` / `X-Channels`; not ready or a 409 returns `DeliveryResult(ok=True, status="skipped")`, which the dispatcher neither records nor counts as failed; `transport: websocket` uses mask's `WS /session/<face>/source` instead: JSON hello `{sample_rate, channels, format: s16le, seed, disclose}`, `ready`, binary PCM frames of at most `WS_FRAME_BYTES` paced at real time + 1 s, `{"type":"end"}`, `done`; a face "already has a source" is skipped; `websockets` imported lazily, connection pinned via `pin()` = one resolve + `argus_cortex.net.check_url`, `process_redirect` refuses every redirect, `proxy=None`, `compression=None`, `max_size` capped). `echo.py`: `EchoSynthesiser(EchoConfig)`, argus-echo's shared HTTP contract re-implemented (`POST /synthesise/stream`, PCM layout from `X-Sample-Rate`/`X-Audio-Format`/`X-Channels`, float32 converted to `pcm_s16le` or WAV) plus the resident contract (`GET /health` as cortex `ResidentHealth`: down or `error` fails fast, `unloaded`/`loading` gets `load_timeout`); bounded body, echo host only, never a GPU lease, failures raise `SynthesisError` (permanent for a 4xx other than 408/429). No `echo` voice channel: echo has no speaker. `redeliver.py`: `RedeliveryJob(store, dispatcher, DeliveryConfig)`, the `redeliver` job (`delivery: {retry_interval, retry_max_age, max_attempts, speak_max_age}`): reports only, failed channels only, never past `max_attempts` or a permanent refusal, text only once older than `speak_max_age`; a `skipped` result writes no row, so it never counts toward `max_attempts`. `build_dispatcher(config, store=, policy_file=, ...)` wires them for the server and the CLI.
- `server/app.py` — `create_app(config, *, store=, budget=, inbox=, sources=, clock=, sleep=, run_scheduler=)` (`[server]` extra). The lifespan builds a `Runtime` (store, policy file, inbox, tariff, usage caps counted in the store, scheduler, metrics registry) on `app.state.runtime`, starts the scheduler and stops it on shutdown; building the app opens nothing. `Runtime.sources` holds the bound sources; `Runtime.channels` / `Runtime.dispatcher` the channels, and `await Runtime.deliver(report)` sends a stored report through them (inbox items reach channels only inside status reports; `Delivery.from_event` and the `event` type are interface for a later single-item path). `deliver_reports(dispatcher)` is the `deliver=` callable passed to `register_jobs`, so briefings and status reports go out as they are stored. Routes: `/health`, `/metrics` (always open, to any `Host`), FastAPI's docs and schema (off under `read_auth`) and the API (`server/routes/`). `install_guards` + `include_routes` are the only API wiring here.
- `server/guards.py` — the security boundary. `install_guards(app, server)`: `HostGuard(trusted_hosts)` outermost (every request but `HOST_OPEN_PATHS` = `/health`, `/metrics`: a `Host` that isn't an IP, `localhost` or a `server.trusted_hosts` name is a 400, against DNS rebinding), then `WriteGuard(constant_refuse)` when `read_only` (the default), then `WriteGuard(cross_site_refuse(allowed_origins, trusted_hosts))`. `write_auth(server)` = `argus_cortex.auth.bearer(token_env)` (no `token_env` → always 503); `source_auth(server)` for the push route = the source plugin's `authorize` (webhook: its own `token_env`, else the server token), credentials first: a name that isn't a push source is 404/405 only to the server token, else the same 401/503 a push source gives; `read_auth(server)` when `server.read_auth`. Auth dependencies carry `AUTH_MARK`; `iter_routes(app)` flattens FastAPI 0.16x's lazily included routers and `unguarded_routes(app)` reports any write route without guards, and a missing or non-outermost `HostGuard`. `read_bounded` / `read_json` (caps `EVENTS_MAX_BYTES` 256 KiB, `ACTION_MAX_BYTES` 8 KiB): write routes take `Request` and read the body after auth.
- `server/routes/` — `events.py` (`POST /api/events/{source}`, all-or-nothing batch, per-event inbox outcome; `POST /api/events/{source}/{event_id}/ack`; `GET /api/events` grouped), `recommendations.py` (manual `approve` / `reject` with `{by, reason, revision}`, proposed only and at the viewed revision, 409 otherwise, applied to the stored row through `store.update_recommendation` with the app clock; `GET /api/recommendations?status=&limit=`, `GET /api/recommendations/{id}` with history; no route past `approved`), `approvals.py` (`GET /api/approvals/rules`: file and runtime rules with `origin` and expiry; `DELETE /api/approvals/rules/{rule_id}` with `{by}`: runtime only, 409 for a file rule, 404 unknown, `by` logged), `reports.py` (`POST /api/reports` `{kind, deliver, no_llm}` through `Runtime.briefings`, 409 while that kind is being written; `GET /api/reports?kind=&limit=`; `GET /api/reports/{report_id:int}` (int, so `/latest` is never shadowed); `POST /api/reports/{id}/deliver` `{force, channels}` as the CLI `deliver`, held to the speech caps), `reads.py` (`GET /api/reports/latest?kind=`, `GET /api/policy/explain`, `GET /wall` as text/plain with control characters stripped, plus what a standing rule approved in the last 24h), `models.py` (request bodies, unknown keys refused; `ApproveBody.standing` mirrors `StandingApprovals.add_from`). An approve with `standing` runs the decision and `add_from` in one `store.transaction()`: both or neither, and a guardrail refusal is a 422 with nothing approved. `Runtime.approvals` is the one `StandingApprovals` the routes and the analysis cycle share (`register_jobs(approvals=)`); runtime rules record `created_by` in their JSON (no migration).
- `server/deps.py` — `get_runtime(conn)` (503 when the app isn't running).
- `server/metrics.py` — `ScoutCollector`, a custom collector on its own `CollectorRegistry` (never the global one) that reads the store, usage caps, tariff file and scheduler at scrape time, so values survive restarts. Families: `scout_usage_used` / `scout_usage_limit{kind}`, `scout_tariff_loaded`, `scout_tariff_period{plan,period}`, `scout_tariff_rate{plan,period,currency,unit}`, `scout_tariff_next_change_seconds{next_period}`, `scout_recommendations{status}`, `scout_approvals_total{source}`, `scout_inbox_open_events{severity}`, `scout_job_runs_total` / `scout_job_errors_total` / `scout_job_last_success_timestamp_seconds` / `scout_job_running{job}`, `scout_deliveries_total{channel,result}`.
- `examples/` (repo root) — commented config for each policy file scout reads; tests load them, so they must stay valid.
- `configdoc.py` — generates `docs/config.md` from the config models (types, defaults, constraints, and each field's `description=` or the docstring under it). Each section's example is validated when it renders. Improve a key's docs in `config.py`, never in `docs/config.md`.
- `docs/` — the guides (`sources`, `signals`, `narrative`, `channels`, `api`, `operations`) plus the generated `cli.md` and `config.md`. argus-handbook imports README.md and `docs/*.md` from `dev`: keep a `#` title first, placeholders in backticks (raw HTML is dropped there), relative links, and no private addresses or paths.
- `src/argus_scout/examples/` — packaged templates `argus-scout init` writes (`scout.yaml`, `env.example` → `.env.example`); tests validate them.
- `deploy/quickstart/` — compose (scout, Prometheus, node exporter, Ollama), its `prometheus.yml` and `config/`. The policy files in `config/` are copies of `examples/`: change both (`tests/test_quickstart.py` fails on drift). `.github/workflows/quickstart.yml` is this repo's own (not copier-managed).

## Conventions & gotchas

- **Versioning is git-tag-derived** (`hatch-vcs`). Never hand-edit a version; `src/argus_scout/_version.py` is generated (gitignored). Tag `vX.Y.Z` to release.
- **`src/` layout, `py.typed`, Pydantic v2, `structlog`.** Ruff line-length 120; keep it clean (`make lint`) before committing.
- **Any endpoint that does something is a boundary.** There's no auth by default — treat reaching the port as host access. Gate state-changing routes behind the shared read-only / origin guards, and fence any caller-supplied path under a configured root.
- Wire schemas (if any) are checked in and verified in CI — regenerate and commit when the types change, don't let the committed copy drift.

## Branches

`dev` is the default branch and the base for every PR. Cut feature branches from `origin/dev` and bring them up to date by merging `origin/dev`, never `main`. Never push work to `main` or open a PR against it, except the release PR from `dev`: `main` must never be ahead of `dev`, with one exception. A release fast-forwards `main` to a `dev` commit that passed CI (`git push origin origin/dev:main`), then tags it. If `main` is protected, the release is a reviewed PR from `dev` into `main`, and merging it leaves a merge commit on `main` alone. That merge commit is the one exception to the rule: it leaves `main` one commit ahead of `dev` with an identical tree. Leave it there and don't merge `main` back into `dev`. Anything else on `main` that `dev` lacks is a mistake (`git diff origin/dev origin/main` must be empty). Once `main` carries such a commit it can't be fast-forwarded, so later releases are PRs too.

## CI / release

CI runs via the shared [`argus-ci`](https://github.com/smk762/argus-ci) reusable workflow. `docs.yml` runs its `docs-check` on every push: published docs (`README.md`, `docs/**/*.md`) must hold no private IPs, home/server paths or personal emails (use placeholders like `<GPU_HOST>`), and `docs/cli.md` must match the CLI — run `make docs` after changing a command or a config model (`docs/config.md` is checked by a test, not by CI's docs job). Release publishes to PyPI (OIDC trusted publishing) + GHCR on `v*` tags. Run `copier update` to pull template (CI/release/tooling) changes.
